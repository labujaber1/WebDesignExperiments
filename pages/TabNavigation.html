Intro

Uses tabs and panels to display each page with height set to 100dvh.

Fixed space for each page, no scroll, overflow hidden.

Promotes concise design.

Tabs have the same background colour as the example pages but could be an image of each page albeit a segment of the page as tabs are set to fixed 5rem height.

Using bootstrap 5.3.8. No extra js beyond that. Css only for tabs styling.

Typically a footer would be at the bottom but the data could be merged within a page layout such as about us

Tabs have set height but can be set to auto with the container set to fit content if more are required.

No scroll and set page height harks back to early internet sites. However, scroll can be added to the page.
