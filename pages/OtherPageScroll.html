Main Page Header

Full page scroll animation for each page or page section to come in and out of view according to entry or exit range. Using animation and view() to change opacity, scale, and border-radius. Wrapped in reduced motion media query but kept animation tied to continuous scroll position rather than execute fully at a given scroll position so the user controls the rate of animation. No jumpy jumpy stuff! Mind you images have not been optimised so maybe a little jerky jerky.
